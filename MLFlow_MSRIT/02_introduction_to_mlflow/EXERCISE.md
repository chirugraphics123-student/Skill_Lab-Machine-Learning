# Lab 02 — Your First MLflow Run: Student Exercise

## Your task
Complete the following independently after running the example once.

1. Change the train/test split `random_state` from 7 to 21 and run the script again.
2. Log a second metric called `test_rows` using the number of test examples.
3. Open the MLflow UI and capture a screenshot of both runs.

## What to submit
- Updated `first_mlflow_run.py`
- Screenshot showing two runs or two run records
- A short note identifying the parameter and metric (MAE is an error metric; lower is better)

## Submission checklist
- [ ] My code runs without an unhandled error.
- [ ] I changed the code/configuration as requested.
- [ ] I included the requested output evidence.
- [ ] I can explain my changes in my own words.
